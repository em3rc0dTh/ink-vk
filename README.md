# Project Ink-VK

> **Chinese Method finds the DNA. Ink makes it belong. VK verifies the transformation.**

Project Ink-VK is a source-to-soul engineering framework for discovering useful existing implementations, extracting reusable intelligence, and transforming that intelligence around the identity, operations, constraints, and intent of a specific client.

This repository is the dedicated versioned knowledge environment for Ink-VK. It follows the same knowledge-governance philosophy used in `knowledge_environment`, while keeping Ink-VK knowledge, sources, iterations, evidence, and future implementation work isolated in its own repository.

## Current state

`STEP 0 — FOUNDATION` is active.

The framework is not frozen yet. Current work is establishing:

- project soul and metaphor;
- terminology;
- framework boundaries;
- source provenance and transformation ethics;
- phase/gate model;
- knowledge structure;
- first formal Ink-VK Framework Contract.

## Knowledge rules

- Meaningful project knowledge must not live only in chat.
- Material iterations are persisted as new versioned artifacts.
- Frozen baselines are historical records and are not silently rewritten.
- Valid older versions remain history; they are not automatically deprecated.
- `deprecated/` is reserved for explicitly invalidated, abandoned, unsafe, or superseded directions that should no longer guide active work.
- Sources and references must retain provenance.
- A recovered source is not automatically an adopted solution.
- Ink-VK must distinguish what was **observed**, **extracted**, **adapted**, **replaced**, and **created new**.

## Safety and legitimacy boundary

Ink-VK is intended for legitimate reuse, adaptation, differentiation, and engineering acceleration. Source licensing, provenance, client ownership, privacy, security, and authorization constraints are part of source selection and transformation decisions.

The Blade Runner / Voight-Kampff mythology is the conceptual identity of the project. It does not redefine the framework as an anti-bot, anti-abuse, or security-evasion system.
