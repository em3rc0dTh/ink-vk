### Company — PASS

The quieter institutional treatment is appropriate. It does not force product/demo visual language into an identity-and-worldview route.

## 5. Non-conformance resolution

This review does **not** reopen the frozen blueprint because the existing blueprint already resolves the issue:

```text
HOME            → strongest 3D / operational network owner
SOLUTIONS       → modular capability device
DEMONSTRATIONS  → evidence/status device
METHOD          → ordered-process / sequence device
COMPANY         → editorial/institutional device
START           → focused-task device
```

The screenshots are accepted as visual composition evidence, but duplicated Home-like hero objects on Demonstrations and Method are **NON-AUTHORITATIVE IMPLEMENTATION DETAILS**.

BUILD may not use screenshot literalism to override the route-device allocation contract.

## 6. Motion / depth interpretation

Static PNGs cannot validate the donor's full experiential character.

The implementation must still prove:

- depth and spatial hierarchy;
- semantic object assembly/transformation;
- section handoff continuity;
- controlled reveal;
- route-specific dominant motion;
- interaction states;
- responsive transformation;
- reduced-motion behavior.

The goal is not to add animation everywhere.

The rule is:

> **Motion must clarify hierarchy, continuity, state, or causality. Decorative motion without a semantic job is not donor fidelity.**

## 7. Provenance boundary

This review authorizes no Dayos asset, source model, shader, animation code, timing curve, proprietary screenshot, design file, or implementation extraction.

R3 experiential fidelity remains separate from R4 direct implementation reuse.

## 9. Framework learning

The VTKALL × Dayos case demonstrates a useful distinction:

> **A visual target can pass Ink before implementation while still containing non-authoritative screenshot details. The frozen blueprint, not screenshot literalism, remains the implementation authority.**

This prevents a rendered concept frame from silently overruling earlier semantic contracts.
