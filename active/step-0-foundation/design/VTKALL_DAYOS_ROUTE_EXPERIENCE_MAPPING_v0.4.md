# 13. Cross-route reusable constraints

The route passes have established several global rules.

## Truth

```text
Donor structure may create a question.
Only target evidence may create target truth.
```

## Non-regression

```text
Donor fidelity may replace target expression,
but may not silently reintroduce known target defects.
```

## Capacity

```text
Design for future capacity; render current truth.
```

## Donor jobs

```text
Match donor jobs, not donor pages as indivisible blocks.
```

## Institutional proof

```text
Narrative depth does not imply institutional proof depth.
```

## Interaction dependency

```text
Visible controls do not prove operational capability.
```
