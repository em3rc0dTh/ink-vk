# 8. Target non-regression contract

Company has no prior target route-specific visual audit.

Therefore:

```text
ROUTE-SPECIFIC DEFECTS → NONE RECOVERED
```

But global VTKALL lessons remain binding.

### NR-C01 — No clipping

Long-form content may extend across multiple viewports.

It must not be forcibly compressed into a viewport and clipped.

### NR-C02 — Wide field must have a job

Do not reproduce the old VTKALL pattern of narrow/crowded content beside large meaningless empty regions.

A wide Company layout may allocate width to:

```text
local rail
editorial typography
conceptual diagram
real evidence/media
```

but unused space must remain compositionally intentional.

### NR-C03 — Multi-viewport is valid

A Company editorial section can be long.

The rule is not `one section = one viewport`.

The rule is:

```text
orientation remains clear
current state resolves
next state enters deliberately
```

### NR-C04 — No accidental section leakage

Use explicit surface/typographic transitions rather than unresolved simultaneous narratives.

### NR-C05 — Closure integrity

```text
EDITORIAL NARRATIVE RESOLVES
        ↓
ACTION STATE RESOLVES
        ↓
FOOTER BEGINS
```

No previous-state + CTA + footer collapse.
