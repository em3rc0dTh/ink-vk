# 24. Framework learning extracted from Home

The reusable route-contract schema is now:

```text
DONOR SECTION JOB
↓
TARGET INFORMATION JOB
↓
TARGET EVIDENCE CLASS
↓
PUBLIC CLAIM CEILING
↓
FILL / REFRAME / OMIT / DEFER
↓
VISUAL FIDELITY CONTRACT
↓
INTERACTION FIDELITY CONTRACT
↓
3D / MEDIA ROLE
↓
PROOF SOURCE
↓
UNKNOWN FIELDS
```

This prevents a common failure in donor-led redesign:

```text
VISUAL SLOT
→ CONTENT INVENTION
```

The desired Ink-VK behavior is:

```text
VISUAL SLOT
→ TARGET TRUTH QUERY
→ TRUTH-PRESERVING TRANSFORMATION
```

**Classification:** `VALIDATED BY VTKALL HOME / CROSS-CASE CANDIDATE`.
