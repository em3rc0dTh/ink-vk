# 6. PLAN entry rule

A useful implementation PLAN may begin only after the Design Freeze pass can state, for every major unresolved item:

```text
FROZEN
or
BOUNDED WITH AN EXPLICIT IMPLEMENTATION-SAFE UNKNOWN
```

Example:

```text
Exact animation milliseconds
may remain tunable during BUILD
only if motion class, trigger, sequence, reduced-motion behavior,
and donor-parity acceptance method are already frozen.
```

Unknowns that change architecture cannot be deferred into BUILD.

---

# 7. BUILD entry rule

BUILD remains blocked until PLAN exists and the implementation contract can identify:

```text
component boundaries
route slices
asset dependencies
responsive acceptance states
motion acceptance states
3D asset path
truth/status assertions
functional dependency ceilings
test/evidence requirements
```

No current artifact authorizes coding yet.
