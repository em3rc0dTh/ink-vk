# 1. Why v0.9 exists

v0.8 closed the primary route-level transformation work and added interaction dependency truth.

The consolidated blueprint exposed a system-level problem:

```text
EVERY ROUTE CAN PASS LOCALLY
WHILE THE PRODUCT FAILS GLOBALLY
```

Possible symptoms:

```text
all routes use the same signature device
proof status differs across pages
density ignores user job
navigation implies nonexistent depth
motion has no hierarchy
route closure changes arbitrarily
responsive behavior loses system continuity
```

v0.9 therefore integrates:

```text
methodology/INK-VK_CROSS_ROUTE_COHERENCE_GATE_v0.1.md
```

Governing rule:

> **Local route validity is necessary; cross-route coherence determines whether those valid routes form one intentional target system.**

# 9. Design Freeze rule

Not every unknown blocks PLAN equally.

Classify remaining unknowns as:

```text
ARCHITECTURE-SHAPING
IMPLEMENTATION-SHAPING
TUNABLE DURING BUILD
FUTURE / NON-BLOCKING
```

### Architecture-shaping

Must be resolved before PLAN.

### Implementation-shaping

Must be frozen or bounded before PLAN can be final.

### Tunable during BUILD

Allowed only when acceptance behavior is already specified.

### Future / non-blocking

May remain deferred if current UI renders current truth.

# 11. Cross-route non-regression

Global target defects discovered in recovery remain active across all routes.

Example:

```text
clipping
crowded center / idle sides
meaningless whitespace
section leakage
CTA/footer collapse
```

A solution on one route does not count if another route recreates the same defect.

# 12. STEP 25 refinement — mode-aware coherence validation

After BUILD, validate both local and global parity.

Questions:

```text
Does each route satisfy its local contract?
Does the global shell behave consistently?
Do surface states retain shared meaning?
Are signature devices allocated by job?
Is status language consistent?
Does motion hierarchy remain intentional?
Does responsive behavior preserve system continuity?
Do routes remain differentiated by purpose?
```

Possible result:

```text
PASS
LOCAL PASS / GLOBAL FAIL
GLOBAL PASS / LOCAL FAIL
NOT TESTED
```

Mode-aware VK requires both local and global success.
